# Upgrade-Win11.ps1 — обновление Windows 10 → 11 без TPM 2.0 и с «неподдерживаемым» процессором

Скрипт делает обновление «на месте» (с сохранением файлов и приложений) и обходит проверки совместимости установщика Windows 11.

> **Важно:** скрипт не тестировался на реальном железе. Успех зависит от версии образа Windows 11 и от вашей конфигурации. Гарантий нет.

---

## Что делает скрипт

0. **Проверки.** Показывает сборку Windows, процессор, ОЗУ, версию TPM, состояние Secure Boot и наличие SSE4.2. Останавливается, если уже стоит Windows 11 или система 32-разрядная, и предупреждает о слабом железе.
1. **Реестр.** Создаёт ключи:
   - `HKLM\SYSTEM\Setup\MoSetup` → `AllowUpgradesWithUnsupportedTPMOrCPU = 1` (документированный Microsoft обход для апгрейда);
   - `HKLM\SYSTEM\Setup\LabConfig` → `BypassTPMCheck`, `BypassSecureBootCheck`, `BypassCPUCheck`, `BypassRAMCheck`, `BypassStorageCheck` = `1` (дополнительные байпасы).
2. **ISO.** Открывает окно выбора ISO-образа Windows 11 (или берёт путь из параметра `-IsoPath`) и проверяет, что это установочный образ Windows.
3. **Копирование.** Монтирует ISO, копирует содержимое в `C:\Win11_Upgrade`, затем отмонтирует образ.
4. **Отключение проверки.** Заменяет `sources\appraiserres.dll` пустым файлом. Этот файл отвечает за проверку совместимости железа.
5. **Запуск.** Стартует `setup.exe` с параметрами `/auto upgrade /compat ignorewarning /migratedrivers all /dynamicupdate disable /eula accept`.

---

## Как запустить

1. Скачайте ISO Windows 11 только с официального сайта: https://www.microsoft.com/software-download/windows11
2. Откройте PowerShell **от имени администратора**.
3. Выполните:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass -Force
   .\Upgrade-Win11.ps1
   ```
   Политика меняется только для текущего окна PowerShell.
4. Подтвердите запуск (`y`), выберите ISO и дождитесь установщика. Компьютер перезагрузится несколько раз, не выключайте его.

### Параметры

| Параметр | Назначение |
|---|---|
| `-IsoPath D:\Win11.iso` | Путь к ISO без окна выбора файла |
| `-ProductServer` | Запустить `setup.exe` с ключом `/product server` (запасной обход) |
| `-Cleanup` | Удалить ключи реестра скрипта и папку `C:\Win11_Upgrade`. Запускайте после завершения обновления |

Журнал работы скрипта: `%TEMP%\Upgrade-Win11.log`. Журналы самого установщика: `C:\$WINDOWS.~BT\Sources\Panther`.

## Нюансы и ограничения

### Что скрипт НЕ обходит
- **Процессор должен быть 64-битным** и поддерживать инструкции **SSE4.2 и POPCNT**. Windows 11 24H2 и новее требует их. На очень старых CPU (примерно до 2009 года) установка не пойдёт ни с какими обходами.
- **Нужна UEFI или совместимая загрузка** и достаточный объём памяти и диска. Windows 11 официально требует от 4 ГБ RAM и 64 ГБ диска, а скрипт отключает именно проверки, не добавляет ресурсов.
- **Ключ `AllowUpgradesWithUnsupportedTPMOrCPU` требует TPM 1.2.** Если в машине нет вообще никакого TPM, один этот ключ не поможет, и тогда вся надежда на замену `appraiserres.dll`.

### Почему результат не гарантирован
- Часть пользователей сообщает, что на 25H2 замена `appraiserres.dll` работает, но есть и отзывы, что ошибка «No TPM» остаётся. Microsoft может усиливать проверки в новых сборках.
- Метод основан на неофициальных обходах. Любое обновление установщика может его сломать.

### Место на диске
- Нужно около **25 ГБ свободного места** на системном диске. Скрипт проверит это и остановится, если места мало.
- Папка `C:\Win11_Upgrade` останется после установки: из неё работает установщик. Удалить её можно командой с параметром `-Cleanup` после обновления.

### Последствия для системы
- Microsoft **не гарантирует** поддержку и обновления на неподдерживаемом железе. Часть обновлений может не приходить.
- Возможны предупреждение «Системные требования не выполнены» в Параметрах и водяной знак на рабочем столе.
- Возможны проблемы с функциями, которые зависят от TPM: BitLocker, Windows Hello, Device Guard, а также некоторые игры с античитом, который требует TPM или Secure Boot.
- Драйверы старого оборудования могут работать хуже. Установщик запускается с `/migratedrivers all`, но не все драйверы переживут переход.

### Безопасность
- **Сделайте резервную копию** важных данных до запуска. Лучше полный образ системы.
- Ключи реестра остаются в системе. Когда обновление закончится, выполните `.\Upgrade-Win11.ps1 -Cleanup`: скрипт уберёт добавленные значения и папку `C:\Win11_Upgrade`.
- Скачивайте ISO только с microsoft.com. Не берите «уже пропатченные» образы со сторонних сайтов.

### Откат
- В течение **10 дней** после обновления можно вернуться на Windows 10: *Параметры → Система → Восстановление → Назад*. Не чистите диск и не удаляйте папку `Windows.old`, пока не убедитесь, что всё работает.

## Если установщик всё равно отказывает

1. **`/product server`**. Запустите скрипт с параметром `-ProductServer`. После обновления останется ваша обычная редакция Windows.
2. **Rufus.** Создайте загрузочную флешку с отключёнными проверками TPM и Secure Boot, затем запустите с неё `setup.exe` прямо из Windows 10 и выберите «Сохранить файлы и приложения».
3. **Чистая установка** с флешки, созданной в Rufus. Файлы придётся переносить вручную.
4. Если ничего не помогло, пришлите точный текст ошибки и модель процессора, по ним можно понять, на какой проверке всё останавливается.
